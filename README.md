# Word Counter

A simple, fast, and modern word counter tool built with React and Vite. Count words, characters, sentences, paragraphs, syllables, reading time, speaking time, and track word density in real-time.

## Stack

- **Framework:** React 19
- **Bundler:** Vite 8
- **Linting:** ESLint 10 (flat config)
- **Styling:** Plain CSS (Neobrutalism design)
- **Deploy:** GitHub Pages

## Scripts

```bash
npm run dev      # Start dev server
npm run build    # Production build
npm run preview  # Preview production build
npm run lint     # Run ESLint
npm run deploy   # Deploy to GitHub Pages
```

## Features

- Real-time text statistics
- Word density analysis with frequency bars
- No external styling dependencies
- Mobile-first responsive design
- Neobrutalism UI
